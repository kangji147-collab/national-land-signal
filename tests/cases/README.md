# 시험 사례 20건 만드는 방법 (작업 1번)

판정 규칙(작업 5번)이 맞는지 채점하는 "정답지"입니다. **정답 판정은 작성자가 국유재산 처분기준을 보고 직접 정합니다.** (AI가 정하지 않습니다)

## 구성: 토지 15건 + 건물 5건

| 종류 | 🟢 | 🟡 | 🔴 | 합계 |
|---|:-:|:-:|:-:|:-:|
| 토지 | 5 | 5 | 5 | 15 |
| 건물 | 1~2 | 1~2 | 1~2 | 5 |

🟢🟡🔴가 골고루 섞이게 해야 "위험한 오판정(🔴인데 🟢)"을 제대로 시험할 수 있습니다.

## 만드는 순서 (사례 1건마다)

1. 토지이음(eum.go.kr)에서 토지이용계획 PDF를 받는다. (건물이면 건축물대장도)
   → `tests/source-docs/land-01.pdf` 로 저장 (파일명은 사례 id와 맞추기)
2. `_template.json`을 복사해 `land-01.json` 으로 이름을 바꾸고, 서류에 적힌 값을 옮겨 적는다.
   - **건축물대장의 소유자 이름은 옮겨 적지 않는다.**
3. 보완 질문 답(`answers`)을 정한다. 일부 사례는 "unknown"(모르겠음)을 섞어 🟡 시험에 쓴다.
4. `expectedSignal`(green / yellow / red)과 이유를 적는다.
5. 현장 사진(시뮬레이션용)은 🟢 사례 중 2~3건에 맞춰 `tests/photos/` 에 둔다. (jpg·png, 얼굴·차량 번호 없는 것)

## 꼭 넣을 사례 유형

- [ ] 규칙표에 **없는** 지역·지구가 나오는 사례 → 🟡
- [ ] 괄호·`<법령 이름>`이 붙은 지역지구 사례 (이름 정리 시험)
- [ ] 국유재산 확인 질문에 "모르겠음"/"아니오"로 답한 사례 → 🟡
- [ ] 사용승인일이 30년 넘은 건물 사례 (노후 안내 시험)
- [ ] 스캔본(글자 없는 PDF 또는 이미지) 서류 1~2건 (그림 판독 시험)

## 주의

- `tests/source-docs/`, `tests/photos/` 는 `.gitignore`에 등록되어 **커밋되지 않습니다.** 사례 JSON만 커밋합니다.
- 소재지는 공개 정보지만, 사람 이름·연락처는 어디에도 적지 않습니다.
